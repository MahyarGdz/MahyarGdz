## Profile

I work across the complete backend delivery path: domain modeling, service
boundaries, API contracts, asynchronous workflows, persistence, container
builds, Kubernetes operations, and production verification.

My strongest work is at system boundaries—where business rules cross services,
authorization must hold across tenants, failures need safe recovery, and a
successful build is not yet a successful deployment.

## Engineering Principles

- Make domain ownership and invariants explicit.
- Fix root causes at the narrowest responsible boundary.
- Prefer simple architecture over speculative abstractions.
- Design failures to be observable and safely recoverable.
- Treat migrations and releases as reversible operational changes.
- Distinguish committed, published, deployed, and live-verified work.
- Operate what you ship.
